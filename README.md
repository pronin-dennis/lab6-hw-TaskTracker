# TaskTracker

TaskTracker — простий консольний застосунок для керування повсякденними завданнями. Проєкт призначений для користувачів, які хочуть зберігати список своїх справ, відстежувати їх виконання та керувати завданнями.

## Можливості

- Додавання нових завдань.
- Перегляд списку завдань.
- Зміна статусу завдання.
- Видалення завдань.
- Збереження завдань у файл.
- Завантаження завдань після повторного запуску програми.

## Встановлення та запуск

Для запуску проєкту необхідно встановити .NET SDK.

1. Клонувати репозиторій:

   ```bash
   git clone https://github.com/pronin-dennis/lab6-hw-TaskManager.git
   ```

2. Перейти до папки проєкту:

   ```bash
   cd TaskTracker
   ```

3. Запустити програму:

   ```bash
   dotnet run
   ```

## Приклад використання

Після запуску програма відображає меню, у якому користувач може вибрати потрібну дію:

1. Додати завдання.
2. Переглянути завдання.
3. Змінити статус завдання.
4. Видалити завдання.
5. Вийти з програми.

Наприклад, користувач може додати завдання «Виконати лабораторну роботу», а після її завершення змінити статус на «Виконано».

# ADR-0001: Використання консольного інтерфейсу

**Статус:** прийнято

## Контекст

Проєкт TaskTracker призначений для виконання базових операцій із завданнями: їх створення, перегляду, зміни статусу та видалення. Для навчального проєкту необхідно обрати простий спосіб взаємодії з користувачем, який не потребує створення графічного інтерфейсу та додаткових бібліотек.

## Рішення

Для взаємодії з користувачем було обрано консольний інтерфейс. Керування програмою здійснюється через текстове меню, у якому користувач вибирає потрібну операцію та вводить необхідні дані.

## Наслідки

Консольний інтерфейс спрощує розробку програми, не потребує додаткових графічних бібліотек та дозволяє зосередитися на реалізації основної функціональності. Водночас інтерфейс має обмежені можливості оформлення та менш зручний для користувачів, ніж графічні застосунки.

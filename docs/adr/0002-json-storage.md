# ADR-0002: Збереження даних у JSON-файлі

**Статус:** прийнято

## Контекст

Завдання користувача повинні зберігатися після завершення роботи програми. Необхідно обрати спосіб зберігання даних, який не потребує встановлення окремого сервера бази даних та підходить для невеликого навчального застосунку.

## Рішення

Для збереження списку завдань було обрано формат JSON. Дані зберігатимуться у локальному файлі, який програма зчитуватиме під час запуску та оновлюватиме після змін у списку завдань.

## Наслідки

Використання JSON спрощує зберігання та перенесення даних, не потребує окремого серверного програмного забезпечення та дозволяє переглядати інформацію у текстовому форматі. Водночас такий спосіб зберігання не призначений для великої кількості даних або одночасної роботи багатьох користувачів, а пошкодження файлу може призвести до проблем із завантаженням інформації.
